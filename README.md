# Artificial Intelligence Practicals

A collection of 12 Artificial Intelligence lab practicals implemented using Python. This repository covers AI agents, search algorithms, problem-solving techniques, machine learning models, logical reasoning, and intelligent applications.

## 📚 Practicals List

| No. | Practical Name | Concepts Used |
|---|---|---|
| 01 | Simple Reflex and Goal-Based Agent | Intelligent Agents |
| 02 | BFS, DFS and Uniform-Cost Search | Search Algorithms |
| 03 | A* Search for 8-Puzzle | Heuristic Search |
| 04 | Minimax and Alpha-Beta Pruning | Game Playing |
| 05 | Rule-Based Expert System | IF-THEN Rules |
| 06 | N-Queens Problem | Constraint Satisfaction, Backtracking |
| 07 | Probabilistic Classifier | Gaussian Naive Bayes |
| 08 | Spam Message Classification | TF-IDF, Naive Bayes |
| 09 | STRIPS Blocks World Planning | AI Planning |
| 10 | Value Iteration in Grid World | Reinforcement Learning |
| 11 | Propositional Logic and Inference | Logical Reasoning |
| 12 | Comparison of AI Learning Models | k-NN, Decision Tree, Naive Bayes |

## ⚙️ Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/Artificial-Intelligence-Practicals.git
   ```

2. Open the project folder:

   ```bash
   cd Artificial-Intelligence-Practicals
   ```

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

## ▶️ How to Run

1. Open the required practical folder.
2. Open the Python file.
3. Run the program using Python:

   ```bash
   python practical_01.py
   ```

4. Check the output in the terminal.
